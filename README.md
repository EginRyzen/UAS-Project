## 📝 Overview

UAS-Project is a full-stack web application framework tailored for property management, built with Spring Boot, Thymeleaf, and MySQL. It offers a secure, modular architecture that simplifies development and deployment of data-driven systems.

**Why UAS-Project?**

This project streamlines the creation of secure, scalable web applications with features including:

- 🛡️ **Security & User Management:** Implements authentication, authorization, and session control for protected user interactions.
- ⚙️ **Modular Architecture:** Facilitates maintainable code with clear separation of concerns across services, repositories, and controllers.
- 🎨 **Rich UI Components:** Reusable templates and components for both user-facing and admin interfaces, enhancing UI consistency.
- 🗃️ **Data Operations:** Supports CRUD functionalities for properties and users, with data seeding for quick setup.
- 📊 **Admin Dashboards & Filtering:** Provides insightful dashboards, filtering, and pagination for efficient data management.
- 🚀 **Rapid Development & Deployment:** Designed for quick iteration and reliable deployment within a cohesive Java ecosystem.

## 🚀 Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language:** Java
- **Package Manager:** Maven

### Installation

Build UAS-Project from the source and install dependencies:

1.  **Clone the repository:**
    ```sh
    git clone [https://github.com/EginRyzen/UAS-Project](https://github.com/EginRyzen/UAS-Project)
    ```
2.  **Navigate to the project directory:**
    ```sh
    cd UAS-Project
    ```
3.  **Install the dependencies using [Maven](https://maven.apache.org/):**
    ```sh
    mvn install
    ```

### Usage

Run the project with [Maven](https://maven.apache.org/):

```sh
mvn exec:java
```
